# devel0mer Homebrew Tap

Official Homebrew tap for CLI tools by [@devel0mer](https://github.com/devel0mer).

## Install `nhilens`

```bash
brew install devel0mer/tap/nhilens
```

Or tap first:

```bash
brew tap devel0mer/tap
brew install nhilens
```

Verify installation:

```bash
nhilens version
```
